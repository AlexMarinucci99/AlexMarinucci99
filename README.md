### The Project

**JiVaio** is a cross-platform mobile application developed to simplify access to urban public transport information in L'Aquila, Italy.

The project addresses a practical mobility challenge: helping students, commuters, residents and visitors find the information they need to navigate the local bus network.

Rather than building another generic navigation platform, JiVaio focuses on the specific needs of a local transport system, bringing together lines, stops, directions and timetables in a dedicated mobile experience.

Developed as an academic project at the University of L'Aquila, JiVaio is a functional prototype that combines mobile development, geospatial information, authentication, persistent data and structured public transport datasets.

### What JiVaio Does

| Feature | Description |
|---|---|
| Public transport exploration | Browse urban bus lines, stops, directions and timetables. |
| Interactive map | Explore the transport network through a map-based interface. |
| Geolocation | Access the user's current position with permission. |
| Guest access | Explore essential transport information without creating an account. |
| Authentication | Sign up and sign in using email/password or Google Sign-In. |
| Favorite lines | Save and retrieve frequently used lines across sessions. |
| Local transit data | Organize and display GTFS-derived transport information. |
| Route search | Demonstrative route-search flow currently using mock data. |
| Notifications | Prototype notification interface prepared for future integration. |

### Engineering Highlights

**Modular application architecture**

JiVaio follows an MVVM-inspired structure, separating presentation, application logic and data access.

Its architecture uses ViewModels, repositories, services and domain models to organize responsibilities and reduce coupling between components.

**Authentication and data persistence**

Firebase Authentication supports account management, while Cloud Firestore provides persistent storage for user-associated information.

**Geospatial and transport data**

The application combines interactive maps, device geolocation and locally processed GTFS-derived datasets to represent the urban transport network.

**State management**

Provider and ChangeNotifier support reactive application state and communication between the UI and application logic.

**Testing and continuous integration**

The repository includes automated Flutter tests and a GitHub Actions workflow for configured CI checks.

**Collaborative development**

Developed as part of the Master Mobile Devs team, bringing together application design, mobile engineering, data organization and project documentation.

### Project Status

JiVaio is a **functional academic prototype**, with its core transport exploration and account features implemented.

Route search and notifications currently include demonstrative functionality and mock data. Real-time transit integration and production-ready routing remain potential areas for further development.

The publicly accessible repository is provided for portfolio presentation and technical evaluation. See its LICENSE file for usage terms.
